# WISECP Website Themes

The website themes that ship with WISECP 5, exactly as they appear in each release package.

| Theme | Folder | Installed at |
|---|---|---|
| Basic | [`Basic/`](Basic) | `templates/website/Basic/` |
| WStyle | [`WStyle/`](WStyle) | `templates/website/WStyle/` |

## Comparing releases

Every release is a single commit tagged with its version (`5.0-beta.1`, `5.0-beta.2`, …). If you maintain a customised copy of a theme, compare the version you started from with the one you are upgrading to, then apply the same changes to your copy:

`https://github.com/wisecp/website-themes/compare/<from>...<to>`

For example: [5.0-beta.1...5.0-beta.2](https://github.com/wisecp/website-themes/compare/5.0-beta.1...5.0-beta.2). All releases are listed under [Tags](https://github.com/wisecp/website-themes/tags).
